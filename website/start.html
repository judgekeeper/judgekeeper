Install judgekeeper
in your project.

  • No API key needed
  • Runs locally
  • Open source

Install in your project’s virtual environment

pip install judgekeeper

Run in your project folder

judgekeeper

Run in your project folder, with nothing to install first (uv)

uvx judgekeeper

Or add it to your project, then run uv run judgekeeper

uv add --dev judgekeeper

Give your coding agent this prompt

Follow www.judgekeeper.com/start.html to run judgekeeper on my project.

It installs judgekeeper, runs it and gives you the marking page link. You mark, then it explains the result.

macOS, Linux and Windows. Python 3.11 to 3.14.

What do you have?

Eval results

Results graded by your LLM-as-a-judge, from

  • promptfoo
  • DeepEval
  • Inspect AI
  • MLflow
  • Your own file

  1. Read.

    Run it in your project folder. It finds your results and opens the marking page. Mark each answer Pass or Fail. Your LLM-as-a-judge’s grade stays hidden while you mark.

    judgekeeper

  2. Measure.

    See how often your LLM-as-a-judge agrees with you, and the answers where you disagree. Too early to tell? Mark more.

    judgekeeper mark

  3. Fix.

    Get the answers it got wrong and write a better rule. Grade the marked answers again with the new rule, and judgekeeper tests it on marks kept aside.

    judgekeeper fix
    judgekeeper fix new-results.json

  4. Re-check.

    Changed its model or rule? Grade your marked answers again and see if it still agrees with you. No new marking.

    judgekeeper check new-results.json

Answers only

Answers from your agent or chatbot, with no grades: a CSV, TSV or JSONL file with input and output columns.

  1. Read.

    Run it in your project folder. Mark each answer Pass or Fail, and add a reason to the failed ones.

    judgekeeper

  2. Measure.

    From 10 marks, see how many passed, with a range.

  3. Fix.

    Get the failed answers, apart from the half kept aside, with a prompt for your coding agent to improve the prompt of your agent or chatbot.

    judgekeeper fix

  4. Re-check.

    Save the new answers over the old file and mark them. On the answers kept aside, see how many were fixed and how many broke.

    judgekeeper

Agent runs

Runs of your agent in a JSONL file, one run per line with an id and its steps.

  1. Read.

    Opens a page with each run’s steps. Click the first wrong step, or All steps are fine.

    judgekeeper steps runs.jsonl

  2. Measure.

    Add the picks of your agent-as-a-judge to see how often it finds the same first wrong step as you.

    judgekeeper steps runs.jsonl --reviewer picks.jsonl

  3. Re-check.

    Change your agent-as-a-judge, save its new picks and run it again. No new marking.

    judgekeeper steps runs.jsonl --reviewer new-picks.jsonl
