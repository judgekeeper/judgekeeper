Check your LLM-as-a-judge.

See how often it agrees with human labels, in one command.

An LLM-as-a-judge is an AI model that grades the answers of another AI model. Teams use one because reading every answer by hand is slow.

Install Check your own LLM-as-a-judge

Free and open source (MIT license). It runs on your own computer. There is no account and no server.

The idea

Three boxes

  1. Your app answers

    Someone asks your AI app a question. The app writes an answer.

  2. An AI judge grades it

    A second AI model reads the answer and says pass or fail. It is fast and cheap. It can also be wrong.

  3. judgekeeper checks the judge against people

    A person grades a small set of the same answers. judgekeeper counts how often the judge agrees with that person.

You see how often the judge agrees with people. Then you decide whether to rely on its grades.

Start here

Install

A terminal is the window where you type commands: the Terminal app on a Mac, PowerShell on Windows. judgekeeper is a Python program, so first check that Python is there.

Mac

Step 1. Check Python. Open the Terminal app and run:

python3 --version

You need 3.11 or newer. No Python, or older? Install it from python.org, then come back.

Step 2. Install judgekeeper.

python3 -m pip install -U judgekeeper && python3 -m judgekeeper --version

If pip says externally-managed-environment, use a virtual environment: run python3 -m venv .venv && source .venv/bin/activate, then install again.

Windows

Step 1. Check Python. Open PowerShell and run:

py --version

You need 3.11 or newer. No Python, or older? Install it from python.org, then come back.

Step 2. Install judgekeeper.

py -m pip install -U judgekeeper
py -m judgekeeper --version

What you see when it is installed:

✓ judgekeeper 0.2.0 is ready
Next: go to your project folder and run judgekeeper start

Linux follows the Mac tab. A command that is not found, or an install that was refused? The full install guide has the fix for each.

Step 3

Run it

Go to the folder of your AI app, where your eval tool saves its results, and run:

cd your-project
judgekeeper start

What you see, for a project with promptfoo results:

Looking in /Users/me/support-bot ...

✓ Your eval tool: promptfoo (results.json, saved 2026-10-03 14:12)
✓ Your judge: llm-rubric "is polite and correct" with openai:gpt-4.1-mini
✓ 212 answers with a verdict: the judge passed 171 and failed 41

You will label answers in your browser, one at a time: Correct or Wrong.
You won't see what the judge said. judgekeeper picks half from the judge's
passes and half from its fails, so you see enough of both.

  A rough check needs 15 Correct and 15 Wrong.
  A reliable result needs 25 Correct and 25 Wrong.
  Most people need 10 to 20 minutes.
