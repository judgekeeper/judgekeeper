Check your LLM-as-a-judge.

See how often it agrees with human labels, in one command.

An LLM-as-a-judge is an AI model that grades the answers of another AI model. Teams use one because reading every answer by hand is slow.

Install Check your own LLM-as-a-judge

Free and open source (MIT license). It runs on your own computer. There is no account and no server.

The idea

Three boxes

  1. Your app answers

    Someone asks your AI app a question. The app writes an answer.

  2. An AI judge grades it

    A second AI model reads the answer and says pass or fail. It is fast and cheap. It can also be wrong.

  3. judgekeeper checks the judge against people

    A person grades a small set of the same answers. judgekeeper counts how often the judge agrees with that person.

You see how often the judge agrees with people. Then you decide whether to rely on its grades.

Start here

Install

A terminal is the window where you type commands. judgekeeper is a Python program, so first check that Python is there.

Open the Terminal app. Check that you have Python:

python3 --version

What you see. Python 3.11 or a higher number. If not, install Python from python.org/downloads and open a new terminal. Now install:

pip3 install judgekeeper

What you see. A few lines. One near the end starts with Successfully installed.

Open PowerShell. Check that you have Python:

py --version

What you see. Python 3.11 or a higher number. If not, install Python from python.org/downloads and open a new PowerShell window. Now install:

pip install judgekeeper

What you see. A few lines. One near the end starts with Successfully installed.

Linux follows the Mac tab. A lower number, an install that was refused, or a command that is not found? The full install guide has the fix for each.
